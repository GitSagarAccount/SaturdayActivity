# Simulation A — Fruit-based diet (scenario definition, not yet run)

Diet of ~60–80% fruit, optional protein supplement, minimal/no exercise, 30–60 day
duration.

**Tracks:** calories, protein adequacy, weight, muscle mass, fat mass, hunger, blood
glucose, triglycerides, LDL, HDL, fiber, potassium, vitamin C, folate, vitamin B12
risk, iron status, dental/GI effects, thyroid-related symptoms, energy/fatigue,
asthma-related exercise tolerance where applicable.

**Guardrail:** a fruit-heavy diet is not automatically healthy — any run of this
simulation must check total calories, protein, micronutrients, sugar load, and the
subject's existing conditions (hyperthyroidism, beta thalassemia minor, asthma)
before projecting outcomes.

No duration, subject, or starting baseline has been selected yet — this is the
scenario definition only.
