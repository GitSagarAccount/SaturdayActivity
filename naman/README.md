# NAMAN

A future simulator project: given physiological, mental-health, and
lifestyle data for a subject, project likely health, psychological, and
sociological outcomes under different scenarios (diet changes,
supplements, life events, etc.).

Kept as a subfolder of SaturdayActivity for now; will move to its own
GitHub repo once one can be created (this session's GitHub App can't
create new repos — see `naman/PROJECT-SPEC.md` history). Nothing here is
code yet — this is the preserved project spec and seed data the simulator
will eventually run on.

## Status

- **Subjects are confirmed dummy/synthetic** — four fictional test
  subjects (Naman, naman2, Nancy, nancy2) created to exercise the future
  simulator, not real people. Confirmed by the project owner on
  2026-10-22.
- No simulator code exists yet. No simulations have actually been run —
  the "simulations" described in the spec are scenario *definitions* for
  the future engine to execute, not results.
- No new data has been invented here. Every value below is exactly as
  supplied; gaps are marked unknown rather than filled in.

## Contents

- `PROJECT-SPEC.md` — the original project-intent document, preserved
  verbatim as the source of truth.
- `subject-registry.md` — the four subjects and their supplied baseline
  attributes.
- `checkpoints/Mar17_2026_v1.0.md` — the frozen baseline checkpoint.
- `simulations/` — one file per planned simulation scenario (fruit diet,
  protein supplement, raw ginger, Supradyn/medication timing, marriage,
  children/inheritance). Scenario definitions only, not run yet.
- `templates/` — the daily-record and lab-result templates the spec
  defines, for when real/simulated data collection starts.
- `missing-data-report.md` — what the spec references but doesn't
  actually supply a value for.
