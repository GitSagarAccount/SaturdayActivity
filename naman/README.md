# NAMAN

Child project, kept inside the SaturdayActivity repo for now (a standalone
GitHub repo couldn't be created from this session — see below). Move it out
to its own repo once one exists and the Claude GitHub App is installed on it.

## Why it's separate from the main app

Spun off to explore ideas that don't fit the main SaturdayActivity (Spark)
dating app's web stack — starting with the Bluetooth earbud-to-earbud audio
relay concept (left earbud mic -> right earbud speaker, both connected to
the same phone). That's not achievable from a browser/web app (no API to
address two Bluetooth audio devices independently), so anything built here
would need to be a native app instead.

Nothing has been built yet — this is just the placeholder workspace.
